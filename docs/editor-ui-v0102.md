# 编辑器界面 0.10.2

编辑器保留桌面游戏开发工作区：顶部菜单和播放控制、左侧层级、中央场景 / 游戏 / UI 视窗、右侧检查器、底部资源 / 控制台。保存、撤销仍使用菜单和快捷键。没有加入 AI 面板，命令接口继续与界面共用操作。

## 控件和视觉

- 顶部居中排列运行、暂停、逐帧、停止四个 SVG 图标。运行使用绿色，暂停状态使用黄色，停止使用红色；不可用的操作置灰。悬停显示功能名和快捷键，右侧文字说明当前状态。
- 保留 F5 运行、F7 暂停 / 继续、Shift+F7 逐帧、F8 停止。逐帧仅暂停时可用；运行中检查器只读。
- 层级、资源、组件、搜索和视图工具使用同一套线宽和尺寸的图标，页签以下划线表示选中，不再用整块高亮按钮表示所有选项。
- Transform3D 的位置、旋转、缩放分别一行，X / Y / Z 用颜色与字母双重区分。字段仍使用原组件键、校验和撤销栈。
- 统一深灰色背景、输入框、分隔线、文字和状态色。布局默认为左侧 244、右侧 336、底部 192 逻辑像素；保留拖动与工作区持久化。分隔线视觉宽 1，拖动范围 5 逻辑像素。
- 菜单 30、主工具栏 48、页签约 30、输入框 24–26 逻辑像素。适用于鼠标键盘桌面编辑器；不是移动端触屏界面。

## 图标格式和运行开销

`editor/icons/*.svg` 是可编辑源文件，24×24 viewBox，白色透明图形，运行时按状态着色。34 个图标为项目内绘制，不依赖 Unicode 符号、emoji 或系统字体图标。

CMake 将 SVG 嵌入编辑器。修改 SVG 后重新构建即可生效；安装后无需网络或另装字体。编辑器使用 bimg 已固定版本携带的 NanoSVG，第一次请求某个图标 / 物理像素尺寸时栅格化，再上传到现有 bgfx 图片图集。之后复用纹理；状态变化只改变顶点颜色。跨 DPI 使用对应物理尺寸，范围限制为 8–128 像素。关闭编辑器时释放图标引用。SVG 解析器只链接编辑器，不进入游戏 Player。

主要实现：`src/editor_icons.*`、`src/editor_theme.hpp`、`src/editor_widgets.inl`。颜色通过主题常量管理；工作区仍由 `editor/editor.ui.json` 配合布局规则描述。

## 验证

`editor_icons_contract` 检查所有图标在 18 / 27 / 36 / 48 像素下的尺寸、透明度、抗锯齿、可着色性及不同图标形状，并拒绝未知名称和非法尺寸。

`renderer_contract` 增加 100% / 150% / 200% 图标尺寸的图集与生命周期检查：同尺寸缓存命中、状态切换零图片上传、合批和显存释放。它需要可用图形设备，其余图标检查无需创建图形窗口。

界面测试使用独立项目副本，避免修改游戏工程。实际窗口检查包括播放状态、XYZ 编辑、资源 / UI 标签以及面板缩放。DPI 的自动验证覆盖图标栅格和 GPU 缓存，不代表已在所有 Windows 缩放设置下完成人工验收。

2026-11-01 本机 Release：19 项 CTest 全部通过，安装验证 9 项通过。实际点击暂停后 ticks 为 533，点击逐帧后为 534 且保持暂停；停止返回编辑模式。位置 X 从 0 改为 2.5 后，Ctrl+Z 恢复 0，文档恢复未修改状态。检查器收窄至 260 逻辑像素时 XYZ 不重叠；UI 资源可双击打开并显示统一的视图工具图标。

## 边界

此次使用已有编辑功能重新组织界面。自由浮动停靠、多选编辑、键盘 Tab 焦点遍历、屏幕阅读器语义树尚未实现，不能把视觉对比度和工具提示等同于完整无障碍支持。项目选择器和系统文件对话框继续使用原生 Windows 控件。
