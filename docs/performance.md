# UI 运行时优化与测量

当前 v0.5 的测量、跨引擎比较及优化取舍见 [运行时比较报告](runtime-comparison-v05.md)。以下保留早期版本的数据，不能当作当前版本的占用或提交次数。

本次把 Player 的通用 JSON 运行树替换为独立的编译资源和 C++ 类型化状态。编辑器与 CLI 保留可读 JSON；`gm_uic` 负责离线编译；Player 只读取 `.gmui`，不链接 `gm_core`、`gm_compiler` 或 nlohmann/json。

## 已实现

- 编译时解析控件类型、字符串 ID、颜色、父子关系和动作参数，剔除编辑器显示名称与节点 ID。
- 二进制使用显式小端字段，包含版本、节点表、动作表、UTF-8 文字区和校验和。加载时验证长度、索引、层级、字段范围和 UTF-8；不会把文件直接强制转换成 C++ 结构体。
- 运行时使用连续节点数组和直接目标索引。计数是整数状态，动作仅更新目标节点，不复制或重新校验整棵树。
- 仅在几何、可见性或窗口尺寸变化后重建布局与按钮区域；文字和颜色变化不会触发布局重建。
- 按原绘制顺序合并相邻且纹理、裁剪状态相同的矩形，不跨越其他绘制操作重新排序。
- 数字与正负号使用按字号缓存的字形图集。数字变化不会生成新的整段文字纹理；v0.5 将其他文字的缓存纹理分配到共享图集页，减少纹理切换；仍采用整段文字栅格化，并非完整字形排版系统。
- 静态 Player 在画面无变化时等待系统消息。当前没有动画或游戏模拟；未来这些系统需要明确安排更新帧，不能照搬无限等待。

## 渲染与静态占用

计数器普通状态原先按代码计数为每帧 11 次绘制提交。新渲染测试实测 10 次，两个连续背景合为一批。悬停边框的 4 个矩形可合为一批。这个小示例的合批空间有限，不代表大 UI 能得到相同或更大的固定收益。

自动渲染测试连续加数 20 次，确认预热后新增文字纹理上传为 0，布局构建次数为 1。数字图集减少纹理变化，但多位数字仍需要对应数量的字形矩形；这些字形在同一批次提交。

静态运行窗口的单次约 5 秒进程采样：旧版一个逻辑 CPU 等效占用约 10.2%、物理工作集约 118 MiB；新版约 1.9%、约 91 MiB。新版 Player 可执行文件为 1,363,456 字节，旧版为 1,452,544 字节。这些是不同时间点的进程快照，受到驱动、后台活动和缓存影响，不是严格对照实验，也没有测量显存或移动端耗电。

## 验证与边界

v0.4 图片资源使用离线解码的 RGBA8 像素，重复路径在单个 UI 内复用纹理。图片示例包含 25 个节点、7 个动作、3 处图片显示和 2 张唯一纹理，编译文件 12,584,223 字节；未压缩像素共 12,581,520 字节，约 12 MiB。v0.4 保留 CPU 像素副本；v0.5 对文件加载的资源在上传后释放该副本，GPU 纹理另占约 12 MiB（不含驱动分配开销），加载时还会有文件缓冲和上传缓冲的临时占用。它消除了运行时 PNG/JPEG 解码，但没有压缩包体或显存。

渲染测试确认：首次上传 2 张图片；7 次适配、着色、不透明度操作中图片上传为 0，布局构建次数不增加；3 次 F5 等价重载后，图片纹理数量仍为 2。当前尚未实现 mipmap、图片纹理图集、按平台 GPU 压缩、跨 UI 文件共享纹理或流式加载。v0.5 增加了 Unity 发行程序的同内容占用测试，见当前报告。

```powershell
ctest --test-dir build -C Release --output-on-failure
.\scripts\test-cli.ps1
.\scripts\test-live.ps1
.\scripts\verify-runtime.ps1
.\scripts\package-example.ps1
```

验证覆盖二进制确定性与往返、截断与损坏拒绝、无效版本和索引、原子重载、实例隔离、节点隐藏、父节点移动、裁剪、缩放命中、计数溢出、布局缓存、合批和数字纹理复用。发布验证将 Player 与编译资源复制到独立目录，确认默认加载成功、拒绝 JSON 与损坏资源，并检查 Player 的实际链接依赖和编译包含文件没有 JSON 文档模块。

运行时仍逐个遍历可见节点提交绘制，通用文字尚未采用完整字形图集，也没有列表虚拟化、离屏 UI 层缓存或完整动画系统。编辑器自身仍使用编辑期 JSON 数据，不计入上述 Player 基准。早期版本没有跨引擎实测；v0.5 报告单独说明已测范围和比较限制。
