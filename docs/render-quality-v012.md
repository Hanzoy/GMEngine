# 0.12：运动闪烁、接触层次与画质验证

后续更新：规则三角阴影条纹已在 [0.12.1](shadow-filter-v0121.md) 修复；跨屏地板横线已在 [0.12.2](ao-bands-v0122.md) 确认为 SSAO 深度采样坐标错误并修复。下文保留 0.12.0 当时的记录。

本轮针对用户提供的 `QQ2026111-19550.mp4`（1920×1110、30 fps、261 帧）做诊断。视频转动时有明显压缩块；引擎自身的采样问题需要用原始连续帧分开验证，不能仅凭压缩视频认定所有闪烁都来自同一个原因。

## 原因与实际修改

| 问题 | 0.11 状态 | 0.12 修改 |
| --- | --- | --- |
| 运动中的边缘与细碎纹理 | 只有单帧 FXAA，没有时间域采样 | 可选 TAA：8 相位抖动、深度重投影、历史遮挡拒绝、邻域/方差限制、Catmull–Rom 重建 |
| 静止时的 TAA 抖动 | 新增 TAA 的首轮实现也出现轻微抖动 | 在稳定输出坐标解析；场景输入连续 32 帧不变后复用已收敛历史，发生变化后恢复更新 |
| 斜视纹理、高频高光 | 普通三线性过滤；高光可小于一个像素 | 各向异性纹理过滤、按法线屏幕导数扩展高光粗糙度 |
| 反弹光采样跳变 | 低分辨率 RSM 随高分辨率阴影步长移动；世界坐标分块随机角度突变 | 共同投影对齐较粗的 RSM 网格，阴影仍是整数 texel 位移；使用固定低差异采样方向 |
| 阴影接收面坡度 | 用平滑顶点法线近似实际三角形深度坡度 | 改为从投影坐标的屏幕导数计算接收面梯度；Sponza 柱面残留斑块仍需单独处理 |
| 接触区域缺少深浅关系 | HDR 环境光无局部遮挡 | 深度预通道、半分辨率 SSAO、深度感知双向滤波；只作用于环境/间接光，保留直射光与自发光 |
| 整体光照偏平 | 环境填充强度相对太阳偏高 | Sponza 重新平衡太阳、天空和曝光，保持模型及纹理内容一致 |

旧版静止视角的 16 帧原始图像相邻差异均值约 `7.23e-8 / 255`，最大 1 级颜色量化。因此本次基线没有发现持续的随机整屏闪烁；运动采样稳定性是主要修复对象。测试过程中曾发现缓存重绘只在 1 / 1,228,800 个颜色通道相差 1 级，GPU 回归对此只允许最多 8 个通道的 1 级量化误差，仍拒绝可见差异。

## 为什么离主流 3A 仍有差距

高面数和大贴图提供的是输入数据，不会自动产生完整的最终画面。目前的差距主要有：

1. **光的传播与遮挡**：我们只有方向光、全局远场 HDR 和一次 RSM 反弹；还没有多次反弹、反弹路径遮挡、室内外探针、区域灯及完整局部光源体系。SSAO 只补屏幕内短距离接触，不能代替 GI。
2. **反射与阴影**：环境反射目前只看到 HDR 天空，不包含周围场景；没有 SSR/局部反射探针或光追反射。方向光仍是单张有界阴影图，没有 CSM、PCSS、接触阴影与虚拟阴影系统。
3. **时间稳定性与材质细节**：本轮补上第一版 TAA、高光过滤和各向异性过滤，但没有逐物体运动矢量、骨骼变形矢量、透明物体反应掩码、成熟的时间超分。现有 glTF 示例还没有保存作者提供的切线基；专用 BC5/高质量法线压缩、切线空间一致性需要继续完善。
4. **场景制作与调光**：Sponza 是建筑测试资源，当前没有完整游戏中的植被、道具、人物、特效、雾、体积光、分层材质、贴花和镜头调色。把它与经过完整美术制作的 3A 成品场景相比，会同时包含渲染器差距和内容差距。

参考：[Epic 高质量时间超采样课程](https://advances.realtimerendering.com/s2014/)、[Filament 材质与高光过滤](https://google.github.io/filament/main/filament.html)、[Lumen 光照和反射](https://dev.epicgames.com/documentation/en-us/unreal-engine/lumen-global-illumination-and-reflections-in-unreal-engine)。这些资料说明采用的技术方向，不表示本引擎已达到相同实现或质量。

## 编辑器、CLI 与项目使用

在 Lighting 实体添加 `RenderQuality` 组件，Inspector 和 CLI 共用组件定义。未添加组件的旧场景保留原来的后处理路径；SDK ABI 仍为 10，旧场景 schema 保持兼容。

```json
{"op":"component.add","id":"lighting","type":"RenderQuality"}
{"op":"component.set","id":"lighting","type":"RenderQuality","field":"temporalAA","value":true}
{"op":"component.set","id":"lighting","type":"RenderQuality","field":"ambientOcclusion","value":true}
{"op":"save"}
```

字段：`enabled`、`temporalAA`、`ambientOcclusion`；`historyWeight` 默认 0.9（0…0.96）；`aoRadius` 默认 1 米（0.05…5）；`aoIntensity` 默认 1.5（0…4）；`aoBias` 默认 0.05（0…0.5）。提高历史权重会增强平滑，也更依赖准确的运动和遮挡判断。Sponza 经相同路线与高分辨率参考对照后选择 0.8，减少高历史权重造成的细节损失。不要用过大的 AO 强度代替缺少的室内光照。

内置 lit 材质已接通。自定义标准网格材质在 `gm_lighting.sh` 中使用：

```c
roughness = gmFilteredRoughness(normal, roughness);
ao *= gmAmbientOcclusion(worldPosition);
// 将 ao 用于 gmEnvironment / gmIndirect；不要乘到直射光或自发光上。
```

引擎额外保留 `s_gmAmbient` 采样槽 14。自定义顶点变形和自定义 alpha 逻辑尚没有专用深度预通道接口，开启 SSAO 前需确认与标准深度 pass 一致。

TAA 历史归属各个视窗。分辨率、镜头参数、场景、灯光、材质、几何变换或相机大幅切换时清除历史。当前没有物体运动矢量，因此动态物体改变时保守地重置整幅历史；这避免旧物体拖影，但动态场景的 TAA 收敛质量仍有限。混合 2D Sprite 与 3D 的游戏视图暂时绕过 TAA，继续使用 FXAA；HUD 和 Canvas 在 3D 后处理之后绘制，文字不参与历史滤波。

RGBA16F 历史双缓冲为每像素 16 字节，半分辨率 RGBA8 AO 双缓冲约每输出像素 2 字节；1080p 合计约 35.6 MiB，4K 约 142.4 MiB。AO 增加一次可见不透明物体深度绘制和三个低分辨率全屏 pass；动态 TAA 增加一个全屏 pass。关闭功能会释放相应资源。GLES3 shader 编译通过，真机移动平台质量/性能尚未验证。

## 连续帧与性能验证

`gm_scene_capture` 的 INPUT JSON 增加 `sequence.frames`（0…600）和 `sequence.commands`（每项包含 `frame` 与 `request`）。每张截图只渲染一次该模拟帧；等待 GPU 读回时不会偷偷增加时间采样或推进游戏。截图写入 OUTPUT 同名子目录的 `frame-0000.png` 等文件。诊断用 `materialOverrides` 可以按 uniform 名覆盖已存在的 vec4 材质参数（数组中的 null 保留原通道），只修改捕获进程内的资产副本，不改变项目文件。

使用相同的相机路线、分辨率和灯光做前后对比；单独关闭 TAA 做消融测试，并用双倍长宽的截图降采样作为有限参考。运动补偿后的帧间残差可以反映稳定性，但受光流误差影响，不能视为完整画质分数。参考图误差与细节锐度也必须一起检查，避免通过模糊画面获得较低闪烁数字。

GPU 单元测试验证实际接触暗化、直射光不受 AO 影响、历史累计/失效、静止收敛、混合 2D 绕过和关闭后的资源释放。Sponza 的最终图像、原始连续帧、消融结果和性能数据保存在游戏项目 `docs/render-quality/`；源码验证摘要位于 `docs/validation/render-quality-v012.json`。

## 仍可观察到的缺陷

近处柱面和拱底仍有三角形状明暗斑块。消融实验中，关闭法线贴图并未消除它；关闭 RSM 减少拱底斑块，但柱面仍存在；关闭阴影后柱面斑块消失。增大阴影偏移会改变光照覆盖并造成脱离接触，不能作为默认修复。本轮没有把这个问题误记为已解决。后续需要分别验证几何接收面的阴影过滤、曲面阴影边界与 RSM 的几何法线采样，并用相同局部截图回归。

## 最终实测结果

用户视频包含运动时的压缩块；原始渲染中的问题主要是运动采样。旧版固定镜头 16 帧基本一致，并非随机整屏亮度变化。新版增加 TAA、各向异性采样、高光过滤、SSAO，并稳定 RSM 的投影与采样方向。

| 同光照、同相机路线，1280×720 | 运动补偿帧间 MAE（0…255） | 双倍长宽参考降采样 MSE |
| --- | ---: | ---: |
| 旧版 0.11 | 1.600404 | 未测 |
| 0.12，关闭 TAA / SSAO | 1.841005 | 19.339830 |
| 0.12，开启 TAA、关闭 SSAO | 1.266981 | 17.823532 |
| 0.12，TAA + SSAO | 1.291369 | 不与无 AO 参考比较 |

TAA 消融对照的运动残差下降 **31.2%**，参考图误差下降 **7.8%**；整套改动在原光照下比旧版残差下降 **19.3%**。静止收敛后 16 帧最大差异为 0。这里的百分比是特定路线的指标，不是完整画质提升百分比。光流估计有误差，参考图还受分辨率相关的材质过滤与 FXAA 影响。

最初采用 0.9 历史权重时稳定性更高，但参考误差略差于关闭 TAA；最终选择 0.8，并保留“不以更高参考误差换低残差”的检查条件。曝光、环境强度在时间稳定性比较中固定为旧值；下方展示与性能测试使用最终太阳 8、环境 3、曝光 1.2。

## 性能与容量

| 模式 | GPU P50 / P95（ms） | CPU 提交前端 P50（ms） | 新增画质缓冲 |
| --- | ---: | ---: | ---: |
| 1080p，TAA / SSAO 关闭 | 0.901 / 1.724 | 0.849 | 0.0 MiB |
| 1080p，开启、静止收敛 | 1.179 / 2.199 | 0.994 | 35.6 MiB |
| 1080p，开启、持续移动 | 1.219 / 2.420 | 0.900 | 35.6 MiB |
| 4K，开启、静止收敛 | 2.228 / 3.166 | 0.917 | 142.4 MiB |

每项预热 60 帧、采样 240 帧；GPU 查询延迟返回，独立去重，不与 CPU 同帧配对。这是隐藏窗口离屏采样、无 VSync，不是游戏呈现 FPS；移动时可见集合改变，不能用移动/静止差直接推算 TAA 成本。静止收敛后跳过 TAA 解析，主场景和 AO 仍然渲染。关闭组是 0.12 关闭新增画质特性，不是旧版二进制。
